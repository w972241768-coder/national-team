# 国家队持仓 · 重点ETF资金看板

宽基 ETF 资金流向监测。用**上交所官方日频份额**推算净流入，配盘中实时行情，
并对「资金流量能否择时」做了 11 年样本的公开复核。

在线地址：https://w972241768-coder.github.io/national-team/

## 这套指标能做什么、不能做什么

- **能做**：回答「谁在买、买哪个风格、相对篮子规模多大」—— 这些是事实。
- **不能做**：择时。2015-01 至 2026-11 共 2873 个交易日、按 20 交易日间隔簇化去重后，
  「滚动 95 分位托底信号」的簇起点 T+20 为 **−0.72%**、胜率 **35%**（基准 +0.25%/52%）。
  分位阈值 80/90/95/98/99 全扫，簇化后都贴着 0 或为负。
- 唯一残留倾向：沪深300 八只篮子单日净流入 > 100 亿（6~7 个独立簇，+3.61%/67%），
  簇数太少，**只能算倾向，不能算规律**，需每季度复核。

## 数据口径

| 项 | 说明 |
|---|---|
| 净流入 | Σ(当日份额变动 × 当日价格)，16 只沪市宽基 ETF |
| 份额来源 | 上交所 `query.sse.com.cn` 日频接口，**T 日份额于次日公布** |
| 价格 / 指数 | 新浪财经日线（前复权） |
| 盘中实时行情 | 腾讯 `qt.gtimg.cn`，浏览器直连（实测返回 `Access-Control-Allow-Origin: *`），26 只 ETF，盘中 15 秒 / 盘后 5 分钟刷新 |
| 篮子缺口① | 深市 9 只（159919 等）：深交所无公开日频份额接口，取不到历史份额，**仅提供行情** |
| 篮子缺口② | **560010 是沪市 ETF**（56 开头），上交所接口确实返回其份额；仅因未纳入历史份额基线而暂未计入，**不是"深交所无接口"**。规模约 92 亿，占篮子约 1.2% |

⚠️ **盘中无法计算当日净流入**：份额次日才公布。页面盘中刷新的是真实时行情，
净流入始终显示最近一个已确认份额日的值，并明确标注日期。

⚠️ **成交额放量基准是估算**：用新浪日线 `成交量 × 收盘价` 换算近 20 日全日日均
（510300 实测 127.23 亿 vs 腾讯快照 125.62 亿，误差 +1.3%）。
盘中今日值是「截至当前时刻累计」，与「全日均值」不可直接相除，
所以页面**只在快照时间已过 15:00 后才显示倍数**，盘中只给参考数。

## 更新机制

- **盘中**：浏览器直连腾讯行情，每 15 秒刷新，不消耗 CI、不需要 token。
- **盘后 / 次日**：GitHub Actions 抓上交所新公布的份额，增量合并基线、重算全部统计，
  写回 `docs/data.json` 与 `docs/state.json` 并 commit（Pages 自动更新）。
- **手动**：页面右下「☁️ 重算数据」→ 粘贴一次 GitHub Token（仅存本机浏览器）→
  触发 `workflow_dispatch`；也可直接去 Actions 页点 Run workflow。

容错：任一数据源不可达时保留基线、写 warning，**绝不写坏数据覆盖线上**；
输出前做 sanity check，不合格直接让 CI 失败，Pages 继续显示上一版。
`docs/state.json` 会持久化上交所连通性探测结果（返回条数），便于不翻需要鉴权的 Actions 日志即可核对。

· 六 篮子构成（含**单只 ETF 当日 / 近 20 日净流入**）与缺口说明
